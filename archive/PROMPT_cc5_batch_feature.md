# คำสั่งสำหรับโปรเจกต์ tidmunz-studio: ปุ่ม "ทำตัวละคร CC5 ทั้งเรื่อง" (กดครั้งเดียวจบ)

## เป้าหมาย
ในหน้านิทาน เพิ่มปุ่ม **"ทำตัวละคร CC5 ทั้งเรื่อง"** เมื่อกดแล้ว
1. โปรแกรมดูว่าเรื่องนี้ยังขาดตัวละครตัวไหน
2. เลือกชุด ผม และรองเท้าให้ทุกตัวเองตามกฎ
3. สั่ง CC5 ทำทุกตัวต่อกันในรอบเดียว
4. ได้ไฟล์ .iAvatar ลงโฟลเดอร์เรื่อง และได้แผ่นรวมรูปให้ผู้ใช้ตรวจทีเดียว

ผู้ใช้ไม่ต้องคลิกทีละตัว และ AI ไม่ต้องคิดใหม่หรือเปิดรูปทีละตัว
งานแบบนี้ต้องเป็นโค้ดธรรมดา (deterministic) ไม่ใช้ AI ระหว่างทำ

- ของที่ลองใส่จริงแล้ว: `snapgen_data\cc5_wardrobe.json` (status ok/broken/rejected, used_by)

  - `cc5_verify_wardrobe.py` รันใน CC5: โหลดทีละชิ้นแล้วจดว่าโหลดขึ้นไหม และชนกับเสื้อหรือกางเกงอ้างอิง → ได้ช่องจริง (upper/lower/full/shoes/hair)
  - `build_wardrobe_verified.py` รวมผลเป็น `snapgen_data\wardrobe_verified.json`
  - ย้ายสองไฟล์นี้เข้าโปรแกรมได้เลย

## กฎเด็ดขาดของผู้ใช้ (ใส่ในโค้ด ไม่ใช่ปล่อยให้ AI จำ)
- ผู้ใหญ่และคนแก่ใช้ร่าง **Neutral เสมอ** เด็กใช้ Child ทารกใช้ Baby ห้ามใช้ Female/Male แม้ข้อมูลจะเขียนไว้
- สีผม: เด็กและหนุ่มสาว = ดำ, วัยกลางคน = เทา, แก่ = ขาว (ค่าสีอยู่ใน hair_pool.colors) และย้อมด้วยวิธีใน `dye_hair()` เดิม
- ผู้ชายห้ามใช้ผมยาวแบบผู้หญิง และ**ทรงผมห้ามซ้ำกันในเรื่องเดียวกัน** (เทียบด้วยชื่อไฟล์ ไม่ใช่ path เต็ม เพราะไฟล์เดียวกันอยู่หลายโฟลเดอร์)
- ชุดชาวบ้านไทยเรียบๆ ไม่โป๊ ไม่แฟชั่น และชุดห้ามซ้ำกับตัวที่อยู่ฉากเดียวกัน (เช่น สามีกับภรรยา)
- ใช้ผมได้เฉพาะ `.rlHair` เพราะ `.ccHair` โหลดใน CC5 ไม่ขึ้น
- ใช้ของที่ status เป็น broken หรือ rejected ไม่ได้
- ส่งเข้าโฟลเดอร์เรื่องแค่ `.iAvatar` ส่วนไฟล์อื่นเก็บใน job folder

## ปัญหาที่เคยเจอ (โค้ดต้องกันไว้)
1. เสื้อกับกระโปรงบางชิ้นเป็นช่อง "full" ทั้งคู่ ชิ้นที่โหลดทีหลังจะทับชิ้นแรก ทำให้ขาเปลือย
   → เลือกชุดจาก `slot` จริงใน wardrobe_verified เท่านั้น ห้ามใช้ full คู่กับ upper/lower
   → หลังใส่ชุดให้ตรวจรายการ wearing ว่ามีท่อนล่างจริง ถ้าไม่มีให้ log FAIL
2. โหลดกางเกงก่อนเสื้อ จะช่วยลดปัญหาเสื้อทะลุ
3. CC5 เปิดนานประมาณ 70 วินาที แล้วมี popup "Failed to establish connection" (กด OK) และถ้าเคยถูก kill จะมี popup "Unsaved project data found" (กด Cancel)
   → ปิด popup ให้อัตโนมัติ เช่นใช้ pywinauto
4. ผมบางทรงมีเตือน texture หาย → กด OK อัตโนมัติ
5. การ Load Python ต้องคลิก 4 ครั้ง → หาวิธีให้ CC5 รันสคริปต์ตอนเปิดเอง (startup script / command-line) ถ้าทำไม่ได้ ให้ผู้ใช้กด Load Python **ครั้งเดียว** แล้วสคริปต์ทำทุกตัวต่อกัน

## ออกแบบ
### ส่วนที่ 1: ตรวจเสื้อผ้า (ทำครั้งเดียว และทำซ้ำเมื่อมีของใหม่)
- ปุ่ม "ตรวจคลังเสื้อผ้า CC5" รัน `cc5_verify_wardrobe.py` แบบทำต่อจากที่ค้างได้
- จากนั้นรัน `build_wardrobe_verified.py`
- หน้าดูผล: แผ่นรวมรูปแยกตามช่อง ผู้ใช้ติ๊ก "ไม่เอา" หรือแก้เพศ/วัยได้
- **Outfit presets** ใน wardrobe_verified.json `presets[]`:
  `{id, label:"หญิงชาวบ้าน 30", gender, age_group, items:[lower, upper, shoes] หรือ [full, shoes]}`
  ให้มีอย่างน้อย 3 ชุดต่อกลุ่ม: ชาย/หญิง × เด็ก/หนุ่มสาว/วัยกลางคน/แก่ และทารก

### ส่วนที่ 2: ทำทั้งเรื่อง
1. **วางแผน** (Python ในโปรแกรม ไม่ใช้ AI)
   - อ่าน story_face_batch แล้วตัดตัวที่มี .iAvatar ในโฟลเดอร์เรื่องแล้วออก
   - ตัวที่ไม่มีรูปหน้า → ใส่รายการ "ขาดรูปหน้า"
   - แต่ละตัว: แปลงวัยเป็น age_group และร่าง แล้วเลือก preset ที่ยังไม่ถูกใช้ในเรื่อง
   - เลือกผมจาก hair_pool ตามกลุ่ม โดยไม่ซ้ำชื่อไฟล์ในเรื่อง
   - เขียน job folder ให้ทุกตัว พร้อม `batch.json` (รายการ job ตามลำดับ)
   - แสดงตารางแผนให้ผู้ใช้กดยืนยันหรือเปลี่ยน preset ก่อน
2. **ทำใน CC5**: แก้ cc5_build_character.py ให้วนตาม batch.json ได้
   - ต่อตัว: new project → Headshot → ใส่ของ → ย้อมผม → ตรวจ wearing → เรนเดอร์ → บันทึก .ccProject → export .iAvatar ไป out_dir
   - ตัวไหนพังให้ log แล้วไปตัวต่อไป ห้ามหยุดทั้งชุด
   - เขียนสถานะลง `batch_result.json` หลังจบแต่ละตัว
3. **ตรวจ**: รวมรูปเรนเดอร์ทุกตัวเป็นภาพเดียว (contact sheet) โชว์ในโปรแกรม
   - ผู้ใช้กด "แก้ตัวนี้" → เลือก preset หรือผมใหม่ → รันแค่ตัวนั้นแบบ skip_headshot
4. หน้าตาในโปรแกรม: ปุ่มเดียว + ตารางสถานะ (รอ / กำลังทำ / เสร็จ / พัง / ขาดหน้า) + แผ่นรวมรูป

## ประหยัด token (สำคัญ)
- AI ห้ามเปิดรูปทีละชิ้น และห้ามถ่ายภาพหน้าจอวน ถ้าต้องดูรูป ให้ดูแค่ contact sheet ใบเดียวต่อรอบ
- ไม่ใช้ computer-use ระหว่างทำตัวละคร ทุกอย่างทำผ่านสคริปต์และไฟล์
- งานนี้ควรจบในงานเดียว ถ้าใหญ่เกินให้แบ่งเป็น 3 ช่วง: (1) ตรวจเสื้อผ้า + presets (2) วางแผน + batch ใน CC5 (3) UI + ตรวจ
- ทดสอบกับเรื่อง "ชีวิตที่ผิดทิศทาง": เสร็จแล้ว 13 ตัว ขาด 8 ตัว (มีหน้าแล้วคือ ปิ่น และ วรรณาวัยสาว ที่เหลืออีก 6 ตัวยังไม่มีรูปหน้า)

## เสร็จเมื่อ
