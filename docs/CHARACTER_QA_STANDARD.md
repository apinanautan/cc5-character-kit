# CC5 CHARACTER QUALITY STANDARD v1.0
วันที่ 2026-10-29 | ใช้กับทุกเรื่องใน CC5 Characters

## สถานะบังคับ
- PASS: ผ่านทุกข้อบังคับ พร้อมหลักฐาน Render และไฟล์ .iAvatar ที่ตรวจแล้ว
- FIX: พบหลักฐานข้อบกพร่องที่ต้องแก้
- REVIEW: มีไฟล์ แต่หลักฐานภาพหรือข้อมูลไม่พอจะยืนยันคุณภาพ
- MISSING: ไม่มีไฟล์ .iAvatar หรือไฟล์อ่านไม่ได้
- NOT_STARTED: ตัวละครยังไม่เริ่มสร้าง

## เช็กลิสต์ตรวจรายตัว
Q01 ตัวละครตรงชื่อ เพศ อายุ บทบาท และจำนวนเวอร์ชันตาม story JSON
Q02 ผู้ใหญ่/สูงวัยใช้ Neutral, เด็กใช้ฐานเด็กถูกต้อง, ทารกใช้ Baby
Q03 ใบหน้าและผมตรงลักษณะตามเรื่อง; ตัวเดียวกันต่างวัยดูเป็นคนเดียวกัน
Q04 เครื่องแต่งกายเหมาะกับยุค ฐานะ อายุ และตัวละคร; เด็กไม่ใช้ชุดผู้ใหญ่ย่อ
Q05 Mesh ไม่มีรู ปุ่มนูนผิดปกติ พื้นผิวเป็นเหลี่ยม แขนผิดรูป หรือส่วนร่างกายเกิน
Q06 เสื้อ-กางเกง-ผิวไม่ทะลุและไม่หาย ตรวจหน้าหลัง ด้านข้าง และท่าเคลื่อนไหว/T-Pose
Q07 ลายผ้า/UV/texture ไม่ขาด ไม่เป็นช่องดำ ไม่ยืดผิดรูป
Q08 รายงาน Polygon และตรวจงบโดยประมาณ: เสื้อ ~12k, ชิ้นล่าง ~15k, ทั้งตัว ~60k-80k (เกณฑ์เตือน ไม่ใช่ตกอัตโนมัติหากมีเหตุผล)
Q09 มีไฟล์ .iAvatar ขนาด > 0, มีภาพ Render และหลักฐาน Save/Export
Q10 ทดลองเปิดไฟล์ .iAvatar กลับใน CC5 หรือ iClone เพื่อพิสูจน์ว่าไม่เสีย (หากยังไม่ทดสอบ = REVIEW)

## วิธีตัดสิน
- ข้อบังคับ Q01-Q07 ผิดจริงข้อใดข้อหนึ่ง -> FIX
- ไม่มีไฟล์หรือเปิดไฟล์ไม่ได้ -> MISSING / FIX ตามความเหมาะสม
- ผ่าน Q01-Q07 และ Q09-Q10 โดยมีหลักฐาน, Q08 ไม่มีปัญหาเกินงบที่ไม่ได้รับอนุมัติ -> PASS
- ยังไม่ได้ดูภาพหลายมุม/ไม่เคยทดสอบเปิดไฟล์ -> REVIEW ห้ามเรียกว่า PASS
- แยก TECHNICAL (มีไฟล์/เรนเดอร์) กับ VISUAL (ตรวจลักษณะ) เสมอ
- อย่าแก้ตัวที่ PASS โดยไม่มีเหตุใหม่; ให้สำรองต้นฉบับก่อนเปลี่ยน .iAvatar

## กฎด้านความปลอดภัยของเครื่อง

ชุด AI ที่พังหนักให้สร้างใหม่; เสื้อ AI ต้อง T-Pose; ตรวจ Render ใกล้ก่อนสรุป
