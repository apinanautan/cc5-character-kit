# HAIR_GUIDE — ทำทรงผมเองใน Blender แล้วส่งเข้า CC5 (สำหรับ AI ตัวต่อไป)

อัปเดต 2026-11-08 · ผู้ใช้อยากได้ผมที่คลังใน CC5 ไม่มี จึงให้ทำผมเองใน Blender

## เป้าหมายตอนนี้
ผมยาวตรง สีดำ แสกกลาง ผมเรียบแนบกะโหลก ทัดหู (เห็นหูเต็มใบ) ด้านหลังเต็มเป็นแผ่นเดียว ปล่อยยาวลงหลัง **ไม่พาดบ่า** ไม่มีดอกไม้
- รูปอ้างอิง: `docs/haircraft_test/ref_4view.png` (หน้า / ข้าง / หลัง)
- ผลที่ดีที่สุดตอนนี้: `docs/haircraft_test/best_so_far.png` ผู้ใช้บอกว่า "เกือบได้" แต่ยังมีช่องว่างเหนือหู/ขมับ
- ตัวที่จะใส่: ปิ่น (job `pin_adult`) แต่ร่างใน job นี้ยังมีหน้าอก ซึ่งผิดกฎ Neutral ต้องแก้ร่างแยกเป็นอีกงาน

## เครื่องมือที่ติดตั้งใน Blender 5.2 (ผู้ใช้ซื้อเอง ติดตั้งเองแล้ว)
| add-on | ใช้ทำอะไร | สถานะ |
|---|---|---|
| **ANA HairCraft Studio** 1.0.2 (`bl_ext.user_default.ana_haircraft_studio`) | ปลูกผมเป็นเส้น (curves) แล้วใส่ geometry node สไตล์ Hair / Stylized / **Cards** | **ตัวหลัก ใช้ Cards เท่านั้น** |
| HairCard Studio (PixelicaCG) | เรนเดอร์ภาพ texture แผ่นผม | ยังไม่ได้ใช้ ใช้ได้ถ้าจะทำ texture ผมเอง |
| StableGen | AI ลง texture / สร้าง mesh (ต้องมี ComfyUI) | ไม่เกี่ยวกับผม |

**บั๊ก ANA บน Blender 5.2:** โค้ดของ add-on ตั้งค่า input ด้วย `modifier['Input_13'] = ...` ซึ่ง 5.2 ไม่รองรับแล้ว ปุ่มเลือกสีและปุ่ม apply จะ error ให้ตั้งค่าเองแบบนี้แทน
`mod.properties.inputs.Input_6.value = material` (Cards: Input_6 = Material, Input_5 = กว้าง, Input_7 = จำนวนซ้ำ, Input_8 = รัศมีซ้ำ, Input_3 = บิด, Input_9 = clump, Input_10/11 = frizz)
ส่วน node group กับ material ให้ append จาก `<addon>/assets/CurveAsset.blend` (เช่น `Cards`, `Cards_Black`)

## วิธีที่ได้ผล (ใช้ต่อจากนี้)
1. ส่งร่างเปล่าออกจาก CC5 (ไม่บันทึกทับอะไร):
   `python tools\cc5.py run cc5\probes\export_body_pose.py job=<job dir> pose=A-Pose out=<body.obj>`
2. รัน `blender\hair_center_part.py` ใน Blender ที่เปิด ANA ไว้ (ผ่าน Blender MCP `execute_blender_code` หรือ `blender --python blender\hair_center_part.py -- <body.obj> <out.blend>`) สคริปต์จะ:
   - สร้างเส้นนำทางเอง 2 กลุ่ม: **ด้านหน้า** เริ่มจากแสก ไหลไปด้านข้างแล้วอ้อมหลังหู กับ **ด้านหลัง** ตกตรงลงมา ไม่มีแสก ทุกเส้นถูกดันออกจากผิวด้วย BVH
   - ใส่ **ANA Cards** แผ่นละ 2.2 ซม. ซ้ำ 5 แผ่น ปิดบิด/clump/frizz ทั้งหมด ผมจึงตรงเรียบ
   - ใส่ **HairScalp** หนังศีรษะสีดำใต้ผม ไม่ให้เห็นผิวขาวลอดช่อง
3. เรนเดอร์ หน้า / ข้าง / หลัง แล้วครอปเฉพาะหัวไปเทียบกับ `ref_4view.png` **ก่อน** ส่งให้ผู้ใช้ดู และต้องซูมดูมุมข้างใกล้ๆ เสมอ (ช่องเหนือหูเห็นชัดเฉพาะซูม)
4. (ยังไม่ได้ทำ) แปลงเป็น mesh ด้วย `sna.curves_to_mesh_68247` หรือ `object.convert`, export OBJ แบบ Y-up (forward −Z, up Y) แล้วนำเข้า CC5 เป็นผม (ดูขั้น export/import ใน `docs/GARMENT_PIPELINE.md`)

## สิ่งที่ลองแล้วไม่ได้ผล (ห้ามทำซ้ำ)
- **ANA สไตล์ "Hair"** (เส้นเรนเดอร์หลายพันเส้น): ออกมาเป็นก้อนดำ ผู้ใช้บอก "ไม่เป็นผม"
- **แผ่น mesh ทึบ** (เปลือกครอบกะโหลก + แผ่นห้อยหลัง): ดูเป็นพลาสติก/ดินน้ำมัน หัวที่ export จาก CC5 มีหน้าน้อย ขอบเลยเป็นขั้นบันได
- **ผมไหลลงตามเส้นรุ้งของหัว**: ผมไหลลงหน้าเป็นหมวกบาตร ผมแสกกลางต้องไหล "ไปด้านข้าง" จากแสก
- **แสกยาวจากหน้าถึงท้ายทอย**: หลังมีร่องแยก ต้องแยกกลุ่มด้านหลังให้ตกตรง
- **ปลายผมไปทางข้าง**: ผมพาดบ่า ผู้ใช้ไม่เอา ปลายต้องไปหลังไหล่ (`yb` ใน `hang`)
- **เปิด frizz/clump/twist ของ Cards**: ผมเป็นลอนกระเซิง ผู้ใช้ไม่เอา
- **ลดจุดอ้อมหลังหูลงมาให้คลุมขมับ** (ทางสามช่วง ลงถึงระดับหูแล้วค่อยอ้อม): ได้ขอบตัดตรงเหมือนหมวก ยังไม่สำเร็จ
- กรองเส้นที่ทับหูแบบตรวจทั้งเส้นรวมช่วงห้อย: เส้นด้านหน้าถูกทิ้งหมด ให้ตรวจเฉพาะช่วงบนหัว (`pts[:nA]`)

## งานที่ค้าง (เรียงตามสำคัญ)
1. **ช่องโล่งที่ขมับ/เหนือหู** มองจากด้านข้างยังเห็นผิว ในรูปอ้างอิงผมคลุมขมับลงมาถึงบนหู แล้วอ้อมหลังหู
   ไอเดีย: ทำกลุ่มเส้นขมับแยก รากอยู่ที่ขมับจริง (หาจาก vertex ของหัวหน้าหู ไม่ใช่จาก ellipsoid) ให้ไหลไปด้านหลังเลียบบนหู ระวังไม่ให้ไขว้กันเป็น X และระวังขอบตัดตรง (สุ่มความยาว)
   ข้อควรระวัง: ตำแหน่งหูที่คำนวณจาก `|x| > 0.07` ไม่แม่น ในภาพหูอยู่ต่ำกว่าที่คำนวณ ควรวัดจาก vertex ของหูจริงก่อน
2. ผมยังไม่เงาเท่ารูปอ้างอิง ลองปรับ material `Cards_Black` (roughness/sheen) หรือทำ texture ใหม่ด้วย HairCard Studio
3. แปลงเป็น mesh → นำเข้า CC5 → ใส่ปิ่น → Conform
4. ร่างปิ่นต้องเป็น Neutral (กฎผู้ใช้)
