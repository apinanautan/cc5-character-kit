# แนวการแต่งกายคนไทยต่างจังหวัด ยุคปัจจุบัน (สำหรับนิทานแนวปัจจุบัน)

ข้อมูลนี้มาจากการค้นรูปชาวบ้านต่างจังหวัด (Bing images, 2026-10-19): ยายใส่เสื้อคอกระเช้ากับผ้าถุง, ลุงใส่เสื้อกล้ามกับผ้าขาวม้า, แม่บ้าน และคนในตลาด

## หลักใหญ่
- ไม่ใช้เสื้อเชิ้ตติดกระดุมเป็นชุดหลัก ยกเว้นชุดนักเรียนและคนทำงานออฟฟิศ
- เสื้อหลักคือ เสื้อยืดคอกลม, เสื้อกล้าม, เสื้อคอกลมผ้าฝ้ายพิมพ์ลายดอกเล็ก, เสื้อคอกระเช้า (ยาย) และเสื้อโปโล
- ผู้หญิงไม่ได้ใส่กระโปรงทุกคน
  - วัยสาว/วัยทำงาน: กางเกงขายาวผ้าเบา, ยีนส์ หรือกางเกงเล
  - แม่บ้านวัย 40: ผ้าถุงปาเต๊ะ หรือกางเกงขายาว
  - ยาย: ผ้าถุงปาเต๊ะหรือผ้าถุงลายดอก
- ห้ามกระโปรงลายสก็อต ลายสก็อตใช้ได้แค่ผ้าขาวม้า (ตาหมากรุก)
- ผู้ชาย
  - เสื้อยืด/เสื้อกล้าม กับกางเกงเล, ขาก๊วย, กางเกงขาสั้น หรือยีนส์
  - คนแก่ใส่เสื้อกล้ามขาว มีผ้าขาวม้าคาดเอวหรือพาดบ่า
- สีหม่นแบบซักบ่อย ไม่สด ไม่แฟชั่น
- รองเท้าแตะเป็นหลัก
