# CC5 Character Studio (app.py)

โปรแกรมหน้าต่างเดียว: วางรายชื่อตัวละครของเรื่อง แล้วโปรแกรมทำทีละตัว ทีละสเต็ป จนได้ไฟล์ `.iAvatar` ในโฟลเดอร์เรื่อง

เปิดโปรแกรม: ดับเบิลคลิก **CC5 Character Studio** บน Desktop (หรือ `CC5 Character Studio.bat`, หรือ `python app.py`)

## วิธีใช้
1. ใส่ **ชื่อเรื่อง** และที่เก็บไฟล์ (ค่าเริ่มต้นคือ Desktop → ได้โฟลเดอร์ `Desktop\<ชื่อเรื่อง>\<โฟลเดอร์ตามข้อ>\`)
2. วางรายชื่อในช่องซ้าย แล้วกด **อ่านรายชื่อ** ใช้แบบเดียวกับที่ส่งให้ AI ได้เลย เช่น
   ```
   1 นายสมจิต+นางอุไร วัยเกือบ40+เกือบ70
   1.1 สมจิตวัย70 แผลไฟลวกที่แขน
   2 ญาติๆ ช-ญ
   3 อรวรรณ ลูกสาว วัยประถม+วัยสาว+ตอนท้อง
   6 ลูกชายอรวรรณ ทารก+4-5ขวบ
   ```
3. เช็กตาราง แล้วดับเบิลคลิกแก้ช่องที่ผิดได้
   - เพศใส่ `m` หรือ `f`
   - อายุใส่เป็นตัวเลข
   - ช่อง "ทำ" ดับเบิลคลิกเพื่อข้ามตัวนั้น (เช่น รถยนต์)
   - หมายเหตุใส่ได้: `แผลไฟไหม้ที่แขน` / `หน้า` / `ขา`, `ผอม`, `ท้อง`
4. กด **ยืนยัน + สุ่มชุด/ผม** โปรแกรมจะเลือกชุด ผม และลายผ้าใหม่ให้ทุกตัว
   - คลิกชื่อตัวละครเพื่อดูว่าได้ชุดอะไร
   - ถ้าไม่ชอบ กด **สุ่มชุดตัวนี้ใหม่**
5. กด **เริ่ม / ทำต่อ** ตารางจะขึ้นสถานะทีละช่อง: ✓ เสร็จ, … กำลังทำ, ✗ พัง, – ข้าม
   - แถวเหลือง = กำลังทำ, แถวแดง = พัง, แถวเขียว = เสร็จ
   - รูปของตัวล่าสุดจะขึ้นด้านขวา
6. ปิดโปรแกรมได้ทุกเมื่อ เปิดใหม่แล้วเลือก **เปิดเรื่องเดิม** จากนั้นกด **ทำต่อ** โปรแกรมจะไม่ทำซ้ำสเต็ปที่เสร็จแล้ว

## สเต็ปของแต่ละตัว
| สเต็ป | ทำอะไร | ต้องมี |
|---|---|---|
| แผน | ตั้งชื่อไฟล์ เลือกเพศ วัย ชุด ผม ลายผ้า | — |
| ลายผ้า | สร้างลายผ้าใหม่ด้วย AI ให้ทุกชิ้นที่เปลี่ยนลายได้ (ถ้า AI ไม่ได้ จะใช้ผ้าในคลังแทน) | Tidmunz Studio (เปิดให้เอง) |
| หน้า | สร้างรูปหน้าด้วย AI (คนเดียวกันต่างวัยจะใช้หน้าวัยแรกเป็นต้นแบบ) | Tidmunz Studio |
| สร้างตัว | Headshot → ใส่ผม ชุด รองเท้า ลายผ้า → ย้อมผม → จัดเสื้อให้อยู่ในหรือนอกกางเกงไม่ให้ทะลุ → เรนเดอร์ → เซฟ | CC5 (เปิดให้เอง) |
| แผล | วาดแผลไฟไหม้ลงบนผิวของตัวนั้นเอง | CC5 |
| แขน | เกลี่ยน้ำหนักแขนเสื้อจากร่างกาย ใช้เมื่อติ๊ก "เกลี่ยน้ำหนักแขนเสื้อ" | CC5 |
| iAvatar | โปรแกรมกดเมนู File → Export → iAvatar ให้เอง ไฟล์เก่าจะถูกย้ายไปเก็บในโฟลเดอร์งาน | CC5 ต้องเต็มจอ และห้ามจับเมาส์ |

คนเดียวกันที่อายุใกล้กัน (ต่างกันไม่เกิน 6 ปี) เช่น ตอนท้อง, ตอนผอม, หรือตอนมีแผล จะใช้หัวเดียวกับตัวแรก แล้วค่อยปรับรูปร่างหรือใส่แผลเพิ่ม

โปรแกรมปิดแล้วเปิด CC5 ใหม่เองทุก 2 ตัว และทุกครั้งที่ CC5 ค้าง

## ความหลากหลายของชุด
- ชุดที่สุ่มได้มีแค่ชิ้นที่เคยใส่จริงแล้วไม่พัง ดูได้ใน `data/outfit_pool.json`
  - ถ้าชิ้นไหนไม่อยากใช้อีก ใส่ `"bad": true`
  - คู่เสื้อกับกางเกงที่ใส่ด้วยกันแล้วหลุด เก็บไว้ใน `"clash"`
- ลายผ้าเกิดจากลวดลายคูณสี (`studio/wardrobe.py` → `PATTERNS`, `COLORS`) แล้วให้ AI สร้างเป็นรูปผ้าใหม่ทุกครั้ง ในเรื่องเดียวกันจะไม่มีลายซ้ำ
- ผมมาจาก `data/app_hair_pool.json`
  - ผมที่ยังไม่เคยใช้จะถูกเลือกก่อน
  - ถ้าผมทรงไหนดูไม่ดี ใส่ `"bad": true`
- `data/history.json` จำว่าเรื่องก่อนๆ ใช้อะไรไปแล้ว เรื่องใหม่จะเลี่ยงของที่ใช้บ่อย
- ผู้หญิงจะได้ทั้งกางเกงและผ้าถุงปนกัน ไม่มีเสื้อเชิ้ตติดกระดุม และไม่มีกระโปรงลายสก็อต (ตามแนวใน `docs/THAI_STYLE.md`)

## ยังไม่ได้ทดสอบกับ CC5 จริง (2026-10-19)
- **Export อัตโนมัติ** ใช้ตำแหน่งคลิกเดียวกับที่ใช้ export 8 ตัวด้วยมือ แต่ยังไม่เคยรันจากตัวโปรแกรมนี้
- **แผล:** ดึงเท็กเจอร์ผิวด้วยการ export OBJ พร้อมเท็กเจอร์ ยังไม่รู้ว่า CC5 ให้ไฟล์ผิวออกมาหรือเปล่า ตำแหน่งแผลที่หน้าและขายังเป็นการกะเอา
- **แขนเสื้อ:** เรียก `TransferSkinWeight("Default")` ได้ แต่ยังไม่ได้ลองกับเสื้อแขนยาว
- **ผอม:** ใช้ได้แค่ slider "face thinner" เพราะชุด skinny เต็มตัวต้องซื้อ license
- **ผมใหม่ 8 ทรง** ใน `app_hair_pool.json` ที่ยังมี `"checked": false` ยังไม่มีใครดูหน้าตาใน CC5
- การสร้างเสื้อผ้าขึ้นใหม่ทั้งชิ้น (mesh ใหม่) ยังทำไม่ได้ ตอนนี้เปลี่ยนได้แค่ลายผ้า และเลือกจากชิ้นที่มีอยู่
